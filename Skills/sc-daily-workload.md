# SC Daily Workload

SC runs these tasks automatically every day on a heartbeat schedule:

## Every 30 Minutes

- Check Supabase for new LowerMyCCPayments.com leads
- If new lead found: save to `Clients/DAA/leads/`, draft follow-up, alert via WhatsApp
- Check Meta ad CPC and ROAS — alert if off threshold

## Every Morning 7AM

- Read `Agency/handoff.md` — what was left unfinished
- Check `follow-up-tracker.md` — who needs contact today
- Pull Facebook insights for BC Homes — save to `Agency/weekly-seo-report.md`
- Generate daily task list and send to WhatsApp:
  > "Good morning Christopher — here's your day:"
  1. Who to follow up with
  2. Any new leads overnight
  3. Top priority task
  4. Any ad alerts

## Every Monday

- Run Moz keyword rank check for all 3 clients
- Pull BC Homes weekly Facebook performance
- Generate weekly report for boss
- Check all Vercel deployments — any errors?
- Summarize week ahead into `handoff.md`

## Every Friday

- Update `business-state.md` with deal status
- Log journal entry to `Building-in-the-Dark.md`
- Send WhatsApp summary: wins, blockers, next week
